1.6 Spatio-Temporal AI Framework
1.6.1 Introduction
This study develops a deep learning model that forecasts temperature from aerosol opti-
cal depth measurements. The model processes sequences of spatial data to predict future
temperature patterns. This approach combines three key components: a feature extraction
network, a spatial processing module, and a temporal learning system.
The model takes sequences of aerosol measurements as input. Each measurement rep-
resents a 19 X 19 grid covering the study region. The model learns to map these aerosol
patterns to temperature distributions at future time points. This prediction task requires
the model to capture both spatial relationships within each time step and temporal patterns
across the sequence.
The methodology addresses three main challenges. First, the model must extract mean-
ingful features from aerosol data that relate to temperature patterns. Second, it must un-
derstand how temperature varies across space while respecting atmospheric physics. Third,
it must learn temporal dependencies that govern how aerosol conditions influence future
temperature.
1.6.2 Data Preparation and Preprocessing
1.6.2.1 Input Data Structure
The input data consists of three aerosol optical depth channels. These channels measure
black carbon aerosol optical depth, sulfate aerosol optical depth, and dust aerosol optical
depth for particles smaller than 2.5 micrometers. Each channel provides a different view
of atmospheric aerosol content. Black carbon primarily comes from combustion processes.
Sulfate aerosols form from industrial emissions and natural sources. Dust aerosols originate
6
from soil and desert regions.
The model receives these three channels at each time step. A sequence length of six time
steps provides enough temporal context for the model to learn meaningful patterns. This
means the model sees six consecutive aerosol measurements before making a prediction.
1.6.2.2 Temporal Encoding
Atmospheric patterns follow seasonal cycles. To help the model recognize these cycles, the
data includes temporal encoding features. These features use sine and cosine functions to
represent the time of year.
The encoding works as follows. Each time step corresponds to a month in the calendar
year. The month number converts to an angle that ranges from zero to two pi radians.
This angle captures the circular nature of seasons. January comes after December, so the
encoding must reflect this continuity.
Two channels encode this temporal information. The first channel contains the sine of
the angle. The second channel contains the cosine. Together, these channels give the model
a clear signal about seasonal position. The sine and cosine values repeat annually, which
matches the seasonal cycle of atmospheric conditions.
1.6.2.3 Autoregressive Features
Temperature at the current time relates to temperature at the previous time. This autoregres-
sive property appears in many atmospheric processes. The model uses this information by
including temperature from the previous time step as an input feature.
This feature gives the model a reference point. When predicting temperature at time t,
the model knows the temperature at time t minus one. This information helps the model
learn temperature changes rather than absolute values. Learning changes proves easier than
learning absolute predictions from scratch.
1.6.2.4 Data Normalization
Raw aerosol and temperature values span different ranges. Aerosol optical depth typically
ranges from zero to several units. Temperature values depend on the region and season.
7
These different scales can cause training problems.
The normalization process standardizes each variable. For the aerosol channels, the
method computes the mean and standard deviation from the training data. Each value trans-
forms by subtracting the mean and dividing by the standard deviation. This transformation
creates features with mean zero and standard deviation one.
The temperature channel receives the same treatment. The normalization uses only train-
ing data statistics. This prevents information from the test set from influencing the training
process. Using test set statistics would create data leakage and invalidate the evaluation.
The normalization parameters come from spatial and temporal averaging. For each chan-
nel, the method computes one mean value and one standard deviation value. These values
apply to all spatial locations and time points within that channel.

1.6.3 Model Architecture
The model architecture follows a hierarchical design. Each component handles a specific
aspect of the learning problem. The first component extracts local features from each input
channel. The second component builds spatial understanding across multiple scales. The
third component learns temporal patterns from the sequence. The final component generates
the temperature prediction.
This separation of concerns makes the model easier to understand and debug. Each
component can learn its task without interference from the others. The components work
together in sequence, passing information forward through the network.

1.6.3.1 Multi-Kernel Block for Feature Extraction
The first component processes each input channel to create feature representations. This
component uses depthwise convolution, which applies different filters to different channels.
This design preserves the identity of each input variable while extracting spatial patterns.
The depthwise convolution operates on each input channel independently using multiple
kernel sizes simultaneously. The architecture processes each channel with several spatial
filters of different sizes. A three by three kernel looks at a local neighborhood of nine
pixels. A five by five kernel examines a broader region of twenty-five pixels. A seven by
seven kernel captures an even wider context of forty-nine pixels. Each kernel size captures
different scales of spatial patterns.
Each kernel size produces one output channel per input channel. With three kernel sizes
applied to six input channels, the operation generates eighteen feature channels. The first six
10
channels come from the three by three kernels, the next six from the five by five kernels, and
the final six from the seven by seven kernels. All outputs concatenate to form the complete
feature representation.
The mathematical operation at each spatial location involves a weighted sum. The
weights form a small spatial filter. For a three by three kernel, nine weights define the
filter. For a five by five kernel, twenty-five weights define the filter. For a seven by seven
kernel, forty-nine weights define the filter. Different sets of weights apply to different input
channels, ensuring each aerosol type receives its own specialized processing.
This multi-scale approach allows the model to capture both fine details and broader con-
text simultaneously. Small kernels detect local patterns like edges and textures. Large ker-
nels recognize extended structures and regional relationships. Processing all scales together
creates a rich representation that captures features across the full range of spatial extents.
After the convolution, batch normalization standardizes the features. This normalization
uses statistics computed across the batch dimension. The transformation includes learnable
scale and shift parameters. These parameters give the model flexibility to adjust the feature
distributions during training.
A ReLU activation function follows the batch normalization. This function replaces
negative values with zero. This introduces nonlinearity, which allows the model to learn
complex patterns. The ReLU function is simple and works well in practice.
The multi-kernel block serves two purposes. First, it expands the feature dimension.
This expansion gives the model more capacity to represent different aspects of the input.
Second, it applies local spatial processing. This processing captures patterns like spatial
gradients and local variations.
Also, the multi-kernel block design preserves channel identity while extracting features.
This matters because different aerosol types have different physical meanings. Black carbon,
sulfate, and dust aerosols affect temperature through different mechanisms.
Processing each channel separately prevents the model from confusing these different
aerosol types. The model learns specific relationships between each aerosol type and tem-
perature. This produces more interpretable and physically grounded predictions.

1.6.3.2 U-Net for Multi-Scale Spatial Processing
The U-Net architecture processes features at multiple spatial resolutions. This multi-scale
approach captures both fine details and broad patterns. The architecture includes an encoder
path, a bottleneck, and a decoder path.
The U-Net also includes squeeze-and-excitation (SE) blocks at each level. These blocks
implement channel attention. Channel attention allows the model to emphasize important
features and suppress less relevant ones.
The squeeze operation computes global statistics for each feature channel. It applies
global average pooling across spatial dimensions. This produces one number per channel
that summarizes the spatial information. This operation compresses the spatial dimensions
while preserving the channel dimension.
The excitation operation processes these channel statistics through two fully connected
layers. The first layer reduces dimensionality by a factor of eight. A ReLU activation in-
troduces nonlinearity. The second layer restores the original channel dimension. A sigmoid
activation produces values between zero and one.
These values act as channel-wise attention weights. Each channel multiplies by its cor-
responding weight. Channels with high weights contribute more to subsequent processing.
13
Channels with low weights contribute less. The model learns these weights during training
based on which channels help predict temperature.
The squeeze-and-excitation mechanism adds minimal parameters. The two fully con-
nected layers contain far fewer parameters than the convolutional layers. The computational
cost is also small because the mechanism operates on compressed channel statistics rather
than full spatial features.
The U-Net serves the purpose of capturing both scales through its encoder-decoder struc-
ture i.e. Local hotspots span a few grid cells & regional patterns span dozens of grid cells.
As the temperature patterns appear at multiple spatial scales, U-Net’s encoder-decoder
structure serves to capture both scales. i.e. Local hotspots span a few grid cells & regional
patterns span dozens of grid cells.
The encoder extracts increasingly abstract features. Early layers capture fine details.
Later layers capture broad patterns. The decoder combines these scales through skip con-
nections. This produces predictions that respect both local and regional structure.
Alternative single-scale architectures would miss either fine details or broad patterns.
The multi-scale approach captures the full range of spatial phenomena.

The Components of U-Net are discussed in detail below:
1. Encoder Path: The encoder path progressively reduces spatial resolution while in-
creasing feature depth. This path consists of four levels. Each level applies two con-
volutional blocks followed by spatial downsampling.
The first level operates at the full 19 × 19 resolution. The convolutional blocks use
three by three kernels with padding. This maintains the spatial size within each level.
Batch normalization and ReLU activation follow each convolution. After processing
at this level, bilinear interpolation reduces the spatial size to 13 × 13.
The second level processes features at this reduced resolution. The number of feature
channels doubles compared to the previous level. This increase in depth allows the
model to represent more complex patterns. After processing, interpolation reduces
the size to 8 × 8.
The third and fourth levels continue this pattern. The spatial size decreases to 3 × 3,
then to 1 × 1. The feature depth continues to increase. This progression creates a
pyramid of features at different scales.

lution decreases, the model can afford to use more feature channels. The total compu-
tational cost remains roughly balanced across levels. Early levels process more spatial
locations with fewer features. Later levels process fewer locations with more features.

1.6.3.3 Long Short-Term Memory (LSTM) for Temporal Sequence Processing
The U-Net processes each time step independently. It produces a spatial feature map for
each input frame. These feature maps need temporal processing to generate predictions
that respect temporal dynamics. A long short-term memory network handles this temporal
processing. The architecture of LSTM is shown Figure 1.2

Feature Sequence Preperation
Before temporal processing, the model flattens each spatial feature map. A 19 × 19
spatial map with one channel becomes a 361-dimensional vector. The model creates one
such vector for each time step in the sequence. These vectors stack to form a sequence with
shape batch by time by 361.
This flattening removes explicit spatial structure. The LSTM receives features as vectors
rather than spatial grids. This simplifies the LSTM processing but discards spatial adjacency
information. The U-Net already processed spatial relationships, so this information exists
within the feature vectors.

LSTM Architecture
The model uses a two-layer LSTM. Each layer maintains hidden states and cell states
across time steps. The hidden state captures short-term patterns. The cell state captures
long-term dependencies.
The first LSTM layer processes the input sequence. At each time step, it receives a 361-
dimensional feature vector. It combines this input with the hidden state from the previous
time step. The combination passes through four gates: forget, input, candidate, and output.
The forget gate decides which information to remove from the cell state. It uses a sig-
moid activation that produces values between zero and one. Values near zero indicate in-
formation to forget. Values near one indicate information to keep. This selective memory
allows the LSTM to discard irrelevant historical information.
The input gate decides which new information to add to the cell state. It also uses a
sigmoid activation. The candidate gate computes potential new information using a tanh
activation. The element-wise product of the input gate and candidate gate determines what
actually enters the cell state.
The cell state update combines these operations. It multiplies the old cell state by the
forget gate output. It adds the product of the input gate and candidate gate. This creates a
weighted combination of old information and new information.
The output gate controls which parts of the cell state affect the hidden state. It applies
a sigmoid activation to determine the gating values. The cell state passes through a tanh
activation and multiplies by these gating values. The result becomes the new hidden state.
The second LSTM layer receives the hidden states from the first layer. Before this trans-
fer, dropout randomly sets some values to zero during training. The dropout probability is
0.4, meaning forty percent of values become zero. This regularization prevents overfitting
by forcing the model to distribute information across many units.
The second LSTM layer follows the same gate structure as the first layer. It produces its
own hidden states and cell states. These states capture higher-level temporal patterns built
20
on top of the first layer’s representations.

1.6.4 Physics Informed Loss Function
The loss function guides model training. A well-designed loss function encourages the
model to learn physically plausible patterns. This proposed framework uses a multi-component
loss function that combines four distinct objectives.
Mathematical Formulation

1.6.4.1 Huber Loss
The first component measures prediction accuracy at each spatial location. It compares
predicted temperature values to actual temperature values. The comparison uses Huber loss
rather than mean squared error.
Huber loss combines properties of squared error and absolute error. For small errors, it
behaves like squared error. This provides smooth gradients that help optimization. For large
errors, it behaves like absolute error. This reduces the impact of outliers.
The transition between these behaviors occurs at a threshold parameter delta. When the
absolute difference between prediction and target is less than delta, the loss equals one half
of the squared difference. When the absolute difference exceeds delta, the loss equals delta
times the absolute difference minus one half of delta squared.
The research uses delta equals 0.5. This relatively small threshold makes the loss robust
to outliers. Temperature predictions occasionally produce values far from the target due to
challenging atmospheric conditions. Huber loss prevents these outliers from dominating the
gradient signal.
The basic Huber loss averages over all examples, time steps, and spatial locations. This
gives each prediction equal weight. An optional enhancement applies temporal weighting.
This weighting emphasizes recent time steps over early time steps in the sequence.
The temporal weights follow an exponential schedule. Early time steps receive lower
weights. Later time steps receive higher weights. The weights sum to one across the se-
quence. A parameter gamma controls the steepness of the exponential. Higher gamma
values create stronger emphasis on recent predictions.
This temporal weighting reflects forecast priorities. In many applications, accurate near-
term predictions matter more than accurate long-term predictions. The model learns to
prioritize recent time steps when this weighting applies.

1.6.4.2 Temporal Consistency Loss
Temperature changes smoothly over time in real atmospheric conditions. Large sudden
jumps in temperature are rare. The temporal consistency loss encourages the model to re-
spect this physical constraint.
The loss compares temperature changes in predictions to temperature changes in targets.
For each time step after the first, it computes the difference between temperature at time t
and temperature at time t minus one. This difference represents the temperature change or
temporal gradient.
The loss measures the mean squared error between predicted changes and actual changes.
If the model predicts smooth evolution and the actual evolution is smooth, this loss is low.
If the model predicts jumps while the actual evolution is smooth, this loss is high.
This constraint embodies the concept of atmospheric inertia. Atmospheric temperature
cannot change instantaneously. Physical processes like radiation and convection operate on
finite time scales. The model must learn these time scales implicitly through the temporal
consistency loss.
The weight on this loss component is 0.7 by default. This substantial weight reflects the
importance of temporal smoothness. Without this constraint, the model might learn to make
independent predictions at each time step. These predictions might be individually accurate
but temporally inconsistent.

1.6.4.3 Spatial Gradient Loss
Temperature varies across space in structured ways. Fronts create sharp gradients. Stable
conditions create smooth fields. The spatial gradient loss helps the model reproduce these
spatial patterns.
The loss examines gradients in two directions: horizontal and vertical. The horizontal
gradient at each location equals the difference between temperature at the current location
and temperature at the location to the right. The vertical gradient equals the difference
between current temperature and temperature at the location below.
The loss computes these gradients for both predictions and targets. It then measures
the mean absolute error between predicted gradients and actual gradients. This comparison
happens separately for horizontal and vertical gradients. The sum of these errors becomes
the spatial gradient loss.
This formulation preserves edge sharpness. Locations with strong gradients in the target
will have strong gradients in the prediction. Locations with weak gradients in the target will
have weak gradients in the prediction. The model learns to reproduce spatial structure rather
than just spatial averages.
The gradient loss uses absolute error rather than squared error. This choice makes the
25
loss less sensitive to the magnitude of gradients. It focuses on matching the pattern of
gradients across space. This works well because gradient magnitudes can vary substantially
across different weather conditions.
The weight on spatial gradient loss is 0.3 by default. This moderate weight balances
structure preservation with magnitude accuracy. Too much weight on gradients could cause
the model to emphasize edges while sacrificing overall accuracy. Too little weight could
produce smooth predictions that miss important spatial details.

1.6.4.4 Structural Similarity (SSIM)
The structural similarity index measures how well two images match in terms of structure
rather than raw values. This metric originally came from image quality assessment. It
26
applies well to spatial prediction problems.
The metric compares three aspects: luminance, contrast, and structure. Luminance refers
to average intensity. Contrast refers to intensity variation. Structure refers to patterns after
removing luminance and contrast effects.
The computation uses local windows rather than global statistics. A Gaussian window
of size seven by seven slides across the spatial grid. At each position, the window weights
define which pixels contribute to the local statistics. Pixels near the window center receive
higher weights. Pixels near the window edge receive lower weights.
For each window position, the metric computes local means, variances, and covariance.
The luminance comparison uses the local means. The contrast comparison uses the local
standard deviations. The structure comparison uses the local covariance normalized by the
standard deviations.
These three comparisons combine into a single similarity score between zero and one.
A score of one indicates perfect similarity. A score of zero indicates no similarity. The
loss equals one minus this similarity score. This converts the similarity measure into a loss
function that decreases as predictions improve.
The structural similarity loss can apply to individual time steps or to all time steps.
Applying it to all time steps increases computational cost but improves temporal consistency.
The default configuration applies it to all time steps.
The weight on structural similarity loss is 0.1 by default. This small weight provides
a subtle signal that complements the other loss components. The metric is scale-invariant,
which means it focuses on patterns rather than absolute magnitudes. This makes it a useful
supplement to the Huber loss, which focuses on magnitudes.

1.6.6.1 Convolutional LSTM for Spatio-Temporal Sequence Learning
Fig. 1.3: Architecture of Convolutional LSTM.
Convolutional Long Short-Term Memory (ConvLSTM) network proposed by Shi et al. ?Shi2015],
is based on the standard LSTM architecture with a convolutional operator in both state-to-
state and input-to-state transitions to be able to capture both spatio-temporal data. ConvL-
STM is tailored to two-dimensional structured inputs, e.g., an image or a grid of geophysical
measurements, as seen in Figure ?? above.
A ConvLSTM uses an input at time t as a multi-channel spatial tensor instead of a one-
dimensional vector, and the hidden and cell states are represented using their spatial time
structure. Thus, the gating functions of the LSTM are represented by the input, forget and
output gates, which are computed through convolution in the spatial grid. This enables
ConvLSTM to collectively learn both spatial relations and temporal relations under one
system.

1.6.6.1.1 ConvLSTM versus LSTM The main difference between ConvLstm and Lstm

the previous hidden state affects the hidden state of a certain position, (i, j) depending on
the size of the convolution kernel. For example, a 3 x 3 kernel allows the grid cell to be
informed with the current cell together with the eight neighbouring cells of the prior time
step.
This is a spatially conscious time-dependent modelling that is specifically significant
to the atmospheric processes involving precipitation, where the weather features are highly
spatially continuous and localised in movement. ConvLSTM has been broadly demonstrated

1.6.7 Summary
This methodology combines established techniques in new ways to analyze the effect of
three aerosol species that is BC, SO4 and DU on near-surface temperature over the NWH
region and also address temperature forecasting from aerosol data.
The multi-kernel block preserves aerosol type identity. The U-Net captures multi-scale
spatial patterns. The LSTM learns temporal dependencies. The physics-informed loss en-
courages realistic predictions.
Each design choice has a clear justification based on either the physics of the problem
or the requirements of effective learning. The architecture balances complexity with inter-
pretability. The loss function balances accuracy with physical plausibility.
The implementation provides flexibility through hyperparameters and architectural op-
tions. This allows adaptation to different datasets and requirements. The training procedure
35
includes appropriate regularization and early stopping to prevent overfitting.
The resulting system provides temperature forecasts that are accurate, physically plausi-
ble, and spatially coherent. The next chapter presents experiments that validate these claims
and compare the approach to alternatives.
